Controller help and input destination
Arrows move. A/S/D = A/B/C, Q/W/E = X/Y/Z, Enter = Start, F = Mode. Form fields never send input. Entering a form, hiding the page or leaving the window releases held buttons. Replay ignores live input. An optional native window can receive keyboard/gamepad input.
